-----------------------------------------------------
1. [MUST] Remove plaintext SUDO_PASSWORD (core/config.py)
-----------------------------------------------------
- Delete the SUDO_PASSWORD line from core/config.py.
- Treat the password as compromised and change it now.
- Deleting the line is not enough: it remains in git history.
  Either rewrite history (git filter-repo or BFG Repo-Cleaner)
  or start a fresh repo from a clean snapshot.
- Load all secrets from core/.env / environment variables.
- Preferably drop sudo support from the agent entirely.


-----------------------------------------------------
2. [MUST] Fix the exec tool guard
-----------------------------------------------------
- The current check looks for the misspelled string "suuudo",
  so it blocks nothing (including real "sudo").
- The protected-path check in tools.py covers only read/write,
  not shell command execution.
- Substring blacklists are easy to bypass. Replace with:
    * a command allowlist, and/or
    * user confirmation before every command
    * a fixed working directory
    * execution timeouts
    * ideally a container or VM sandbox
- Treat any skill or prompt that can reach exec as having
  full shell access until this is fixed.


-----------------------------------------------------
3. [MUST] Harden path checks
-----------------------------------------------------
- Resolve paths with os.path.realpath() before comparing them
  against the protected list (/etc, /boot, /usr, ~/.ssh, etc.)
  so "../" and symlinks cannot bypass it.
- Consider an allowlist of writable directories instead of a
  blocklist of protected ones.
